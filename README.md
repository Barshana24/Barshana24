- Making local LLMs do real work: a generator that reads a whole codebase and writes its docs, a reviewer that scores code across ten dimensions and exports a PDF, and a Chrome extension that trims prompts before they get sent. All of it runs offline on Ollama.
- Contributing to [AOBench](https://github.com/MSKazemi/aobench), a benchmark for AI agents that operate HPC systems.
