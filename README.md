## Featured projects

**[SIGLO](https://github.com/Barshana24/Siglo-GTM-tool)**: GTM intelligence platform built during my internship. FastAPI + PostgreSQL backend, integrates Nexl CRM, Postilize, and Microsoft Graph/SharePoint, with an AI layer for outreach generation.

**[FunellQ](https://github.com/Barshana24/FunellQ)**: Funnel and conversion analytics on GA4 e-commerce data. Next.js + BigQuery SQL, [live on Vercel](https://funellq.vercel.app).

**[EduBot](https://github.com/Barshana24/EduBot)**: Multilingual AI tutor for engineering students, with quizzes, flashcards, interview prep, and RAG over your own notes. FastAPI + React, local LLM via Ollama.

**[PromptShrink](https://github.com/Barshana24/Token_minimiser)**: Chrome extension that trims 15-45% of the padding out of a prompt before you send it, with unit tests proving it never touches your code blocks.

**[company-name-normalizer](https://github.com/Barshana24/company-name-normalizer)**: Fuzzy-matching engine that cleaned up company name inconsistencies across CRM survey data at Baretz+Brunelle.
